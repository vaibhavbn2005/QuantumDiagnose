# QuantumDiagnose

QuantumDiagnose is an educational Flask web application that demonstrates machine-learning based symptom classification.

## Features
- Doctor-style symptom selection interface
- Naive Bayes disease classification
- Confidence score and top 3 predictions
- Flask JSON prediction API
- Vercel deployment configuration
- CSV-based training data

## Run locally

```bash
pip install -r requirements.txt
python api/index.py
```

Open `http://localhost:5000`.

## Important
This is an educational software project. Predictions are not medical diagnoses and should not be used for medical decisions.
